# Portfolio decks

Sources for the two Slides decks in Claude, built from the same copy as mancinitan.com.

- `detailed.py`: "Portfolio · Detailed case studies", the full long-form cases (for reading or PDF).
- `present.py`: "Portfolio · Interview presentation", short slides with a speaker script on each.
- `kit.py`, `layouts.py`: shared look (Sage palette, Archivo and Archivo Narrow) and slide layouts.
- `assets.py`: uploaded image addresses for each deck.

Each case is its own section in both decks, so slides can be mixed and matched per role.
Any copy change on the site should be made here too, then both decks republished.
